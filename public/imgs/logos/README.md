# Owner-Provided Logo Slots

Place licensed or rights-cleared third-party logo files here if the site owner has permission to display them.

The popular lineup carousel is configured to try multiple extensions automatically.

For example, for Netflix it will try:

- `netflix.svg`
- `netflix.png`
- `netflix.jpg`
- `netflix.jpeg`
- `netflix.webp`

So you can add whichever one you have.

Logo base filenames:

- `bein-sports`
- `netflix`
- `hbo`
- `espn`
- `sky-sports`
- `dazn`
- `disney-plus`
- `prime-video`
- `tnt-sports`
- `canal-plus`

If a file is missing, the website automatically falls back to a premium styled text pill, so the site will not break.

Recommended format:

- Use `.svg` for logos when possible, but `.png`, `.jpg`, `.jpeg`, and `.webp` also work.
- Keep logos transparent-background.
- Use consistent visual weight so the carousel looks balanced.
- Do not add any official logo unless you have the rights or authorization to use it.
